# 宝贝学乐园 · KidGame 🐣

给幼儿园小班小朋友的粤语启蒙小游戏：看图 + 听语音就能玩，边玩边学，答题攒星星，星星可以兑换真实奖励。

## 怎么玩

双击 **index.html** 就能在浏览器里玩，不需要联网、不需要安装任何东西（也可以拷到 iPad 上用 Safari 打开）。部署到 GitHub Pages 后也可以直接在线玩。

## 游戏内容

- **四大学习主题**：数字（认数字 / 点一点数数）、颜色、形状、动物 —— 卡通角色 + 中文语音引导，不用认字
- **三档难度**：每个主题可选 简单 ⭐ / 普通 ⭐⭐ / 困难 ⭐⭐⭐（选择会记住）；困难模式 4 个选项、数字到 20、数到 10、10 种形状、14 种动物
- **丰富玩法**（同一主题随机轮换，不再只是找一找）：
  - 数字乐园：找数字 / 数一数 / **比多少**（左右两组点多的）/ **按顺序点数**（1→N 依次点）
  - 颜色王国：找颜色 / **彩虹补色**（给缺色的彩虹补上正确颜色，有填色动画）
  - 形状城堡：找形状 / **影子配对**（看黑色剪影找同形状）
  - 动物森林：找动物 / **听声音猜动物**（只播报"汪汪汪"，靠听力找动物）
- **主题化场景**：每个世界有专属配色背景和漂浮装饰（数字积木 / 彩虹颜料 / 几何图形 / 森林伙伴），连对 3 题出现火焰 🔥
- **星星奖励**：答对得星星，连对 5 颗奖大星星；底部小星星实时显示答题进度
- **星星商店**：主页右下角礼物按钮进入，星星可以兑换贴纸（3★）、益力多（5★）、气球（6★）、雪糕（8★）、恐龙玩具（10★）、神秘礼物盒（20★），兑换后找爸爸妈妈领取实物；星星不够的奖品会显示"还差 N 颗"
- **语音按钮**：每个奖品卡右上角有小喇叭，点一下读奖品名（益力多说成"多多"）
- **语音**：默认粤语（善怡发音人），右上角"粤/普"按钮可切换普通话，话术全部本地化；找不到粤语发音人时页面会提示安装方法
- **背景音乐**：小星星 / 两只老虎轮播，右上角可开关
- **字体**：内嵌站酷快乐体子集，离线也是卡通字体

## Docker 部署

本机已安装 Docker 的话，也可以用容器方式在家里的设备上长期运行：

```bash
# 方式一：docker compose（推荐，含自动重启）
docker compose up -d          # 构建并启动，访问 http://localhost:8080
docker compose down           # 停止

# 方式二：纯 docker
docker build -t kidgame .
docker run -d --name kidgame -p 8080:80 --restart unless-stopped kidgame
```

启动后局域网内的设备（如 iPad）可通过 `http://<电脑IP>:8080` 直接访问。

## 小提示

- 星星数量和兑换记录保存在浏览器本地：同一台电脑、同一个浏览器才延续；换设备或清除浏览器数据会重新从 0 开始
- 首次进入需要点一下"开始"按钮，浏览器才允许播放声音
- **手机/平板没声音？** ① 检查设备是否开了静音（iPhone/iPad 侧边开关），媒体音量是否调大；② 游戏切到后台再回来会自动恢复声音；③ 背景音乐音量做了加大处理，若仍偏小属正常，可在系统音量里调高
