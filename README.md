# 宝贝学乐园 · 使用说明

给小班小朋友的粤语启蒙小游戏，边玩边学。

## 怎么玩

双击 **宝贝学乐园.html** 就能在浏览器里玩，不需要联网、不需要安装任何东西（也可以拷到 iPad 上用 Safari 打开）。

## 游戏内容

- **四大学习主题**：数字（认数字 / 点一点数数）、颜色、形状、动物 —— 看图 + 听语音就能玩，不用认字
- **星星奖励**：答对得星星，连对 5 颗奖大星星
- **星星商店**：主页右下角礼物按钮进入，星星可以兑换贴纸（3★）、益力多（5★）、气球（6★）、雪糕（8★）、恐龙玩具（10★）、神秘礼物盒（20★），兑换后找爸爸妈妈领取实物
- 每个奖品卡右上角有小喇叭按钮，点一下听奖品名（益力多说成“多多”）
- **语音**：默认粤语（善怡发音人），右上角“粤/普”按钮可切换普通话；商店里找不到粤语发音人时页面会提示安装方法
- **背景音乐**：小星星 / 两只老虎，右上角可开关

## 小提示

- 星星数量和兑换记录保存在浏览器本地：同一台电脑、同一个浏览器才延续；换设备或清除浏览器数据会重新从 0 开始
- 首次进入需要点一下“开始”按钮，浏览器才允许播放声音
